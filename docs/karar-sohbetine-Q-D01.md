# Q-D01 — ürün kararı ve runtime aktarımı mevcut

Karar kaynağı [Q-D01 kabulü](../contracts/10-FtkSaaS-Q-D01-kabul-karari.md). İlk [teknik aktarım raporu](../contracts/11-FtkSaaS-Q-D01-teknik-aktarim-raporu.md) tarihsel kanıttır; güncel durum veya açık iş listesi değildir.
