## Router + Query birleşik veri yaşam döngüsü (açık)

**Hedef:** Var olan Vite/React/TanStack mimarisini koruyarak güvenli, tenant kapsamlı, doğru, iptal edilebilir ve ölçülmüş en az API isteğiyle çalışan SPA. _Yeni state store, ikinci cache, genel event bus, bütün mutation'ları yeniden yazma veya ölçümsüz backend API tasarımı yapılmaz._

**İlk kaynak denetimi.** `8a5efbb0c14ea259246ca9d07f1fb92948007557` üzerindeki 50 route, 36 feature alanı ve ilgili Query/reader/mutation kodu; kod aramasında `queryKey` eşleşmeli 127 dosya ve `onRefresh` eşleşmeli 116 dosya. Bu statik tarama yeni bir CI/test veya canlı performans kanıtı değildir. Bulguların açıklama ve teknik tercih sahibi [geliştirme rehberidir](development.md#router--query-birleşik-veri-yaşam-döngüsü).

## Frontend TypeScript tip güvenliği (açık)

**Denetim:** 23 Kasım 2026, `main` `1ecad263a392a8112665cb6dd1d3b57e670c27fe`. `strict` typecheck başarılı; 883 frontend/ortak UI TypeScript dosyasında açık `any` yalnız üretilmiş `routeTree.gen.ts` içindeki 49 `as any` kullanımıdır. TypeScript tip çözümleyicisinde uygulama kaynaklarında **35 örtük `any` konumu** (aynı kökten türeyenler dahil); ek Oxlint `no-unsafe-*` denetiminde **28 üretim dosyasında 77 uyarı** görüldü. Uyarı sayısı bağımsız hata sayısı değildir. E2E/CI betiklerine ait uyarılar ayrı değerlendirilecek.

**Kapsam kararı:** Hazır kütüphaneler, `node_modules`, Vite/Playwright/TanStack kaynakları, üretilmiş API tipleri ve `routeTree.gen.ts` **değiştirilmeyecek**; Router'daki `@ts-nocheck` korunur. İlk taraf tüketici, config, transport ve test yardımcıları düzeltilir. Mevcut Zod/typed kontrolleri yeniden yazma; yeni bağımlılık, ikinci genel validator/cache katmanı ve büyük ölçekli soyutlama ekleme. İşlerin **yürütme sırası** [production-queue.md](production-queue.md#tip-guvenligi-sirasi) sahibindedir.

- [ ] **TS01 · P1 · Native API yanıt güven sınırı.** [Zarf okuyucusu](../src/lib/backend.ts) `result.data as T["data"]` ile kontrol edilmemiş veriye derleme zamanı tipi atıyor. Mevcut sözleşme/Zod olan kritik aktör, yetki, finans ve işlem-sonucu okumalarında gerçek `unknown`→doğrulanmış DTO sınırı kur; bütün operasyonları tek seferde yeniden modelleme. **Kabul:** Bozuk `ok/data`, yanlış DTO, tenant/aktör ve başarısız receipt/readback senaryoları açıkça reddedilir; geçerli native veri, hata kodları ve komut idempotency davranışı değişmez.
- [ ] **TS02 · P1 · Ortam yapılandırması kaynaklı örtük `any`.** [Supabase](../src/lib/supabase.ts), [public gateway](../src/lib/public-gateway.ts), giriş/oturum ve rapor kaynaklarında `import.meta.env.VITE_*` değerleri `any` gibi yayılıyor. - [ ] **TS03 · P1 · Rapor dosyası, yükleme ve public istekler.** [Rapor komutu](../src/features/reports/reports-command.ts), [public takvim](../src/features/public-program/public-calendar-read.ts), [başvuru](../src/features/public-program/public-application-submit.ts) ve [Turnstile](../src/features/public-program/public-turnstile.tsx) üzerinde TS02 kaynağından gelen güvensiz URL/başlık/değer kullanımını temizle.
